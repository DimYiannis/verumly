# Name options

**Chosen: Verumly** (2026-10-19, replaces Syngrapha, which was applied on the same day). Built on the Latin "verum" (the true thing). **Caution:** it is close to "Verum", which several others use, notably Verum Messenger / Verum Finance (London, a privacy-first messenger with money transfers, launched 2026) and Verum Mail. Nothing named "Verumly" turned up on the web, npm, PyPI or GitHub (user), and verumly.io/.app/.eu/.nl looked free by DNS (.com taken), but a trademark opposition from the Verum family is a real risk: do the EUIPO/BOIP search (classes 9, 36, 42) before investing. Earlier choice: Syngrapha, the Latin word for a written agreement signed by both parties. The old working name was "bonnen" (placeholder). No conflict was found on the web, npm, PyPI or in a GitHub search, but the official trademark search (EUIPO, BOIP; classes 9, 36, 42) has not been done yet; the .com is taken (io, app, eu, nl looked free by DNS). Domains were checked on 2026-10-18 **by DNS only**: "free" means the domain has no name servers, not that the registry says it is available. Nothing here was checked for trademarks, GitHub, npm or the app stores. Check the registrar and the trademark databases before buying or committing to a name.

## What a receipt is (the idea behind the names)

A receipt is the portable proof of an exchange that already happened. It has two sides with different interests (the shop issues it by obligation, the customer keeps it by choice), it is a fact that is not rewritten (it is cancelled or corrected by a new version), and its value is that it was produced then, by that terminal.

The oldest form of that idea is a token broken in two, one half for each side, that only fits if the exchange was real: the Greek **symbolon** (the origin of "symbol"), the Roman **tessera hospitalis**, the tally stick, and the Italian "matrice e figlia" of the old receipt books. A "cambiale" (bill of exchange) is not the same thing: it promises a future payment.

## Recommendation

1. **Symvolo**: the idea of the two matching halves, works for businesses and for people, short, every domain free.
2. **Symvolon** if we want to stay closer to the ancient word.
3. **Synthema** if the agreement between two parties matters more than the two halves (only app and nl are free).
4. **Greentally** if a plain, friendly name is wanted instead.

## Before deciding

- Check the chosen name on the registrar (not only DNS), on GitHub, npm, the App Store and Google Play, and in the trademark databases (EUIPO, BOIP for the Netherlands).
- Then rename in one pull request: logo, page titles, the landing site copy, the wallet manifest and the dashboard.
